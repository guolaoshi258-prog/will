PROJECT 03 / AI AGENT

Outflow — 对话式支出管理 Agent

从票据识别、结构化数据，到工具调用和自然语言查询。

项目简介

把票据变成可查询的支出记录

Outflow 是一个票据与支出管理 Agent：从 Receipt 输入，到 OCR 与信息抽取，再形成结构化数据，并支持自然语言查询。

核心问题

让模型负责理解，让工具负责计算

大模型擅长理解语言，但并不适合直接处理精确的财务计算。项目重点是减少数字场景中的幻觉，把计算交给 Calculator 或 Tool，并通过结构化数据进行 grounding。

项目流程

Receipt→OCR / Extraction→Structured Data→Calculator / Tools→Natural Language Query→Grounded Answer

方案重点

模型、工具与数据各自完成最适合的部分

  • OCR 与票据信息抽取
  • 结构化数据存储
  • Tool Calling 与精确计算
  • Grounding 与幻觉控制
