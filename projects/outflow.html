CASE STUDY

Outflow — Conversational Expense Agent

A conversational expense assistant that turns receipts into structured records and answers financial questions with grounded calculations.

AI AgentOCRGrounding
OVERVIEW

What this project was about

The system turns receipts into structured expense data, stores the result, and allows users to ask natural-language questions about spending.

CHALLENGE

What made it difficult

LLMs are good at language but unreliable for exact financial arithmetic. The system therefore needed to separate extraction, storage and calculation from free-form generation.

SOLUTION

How I approached it

The workflow uses OCR / extraction for receipts, structured records for persistence, a calculator/tool layer for numerical operations and grounded natural-language responses for the user interface.

Receipt→OCR / extraction→Structured data→Calculator / tools→Natural-language query→Grounded answer
MY CONTRIBUTION

What I owned

I helped frame the product flow, evaluation priorities and interaction design around a simple goal: make conversational finance convenient without sacrificing numerical trust.
