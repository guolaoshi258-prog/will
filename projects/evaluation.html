PROJECT 04 / EVALUATION

LLM / Agent Reliability Testing

围绕正确性、安全性、成本与边界样本建立可重复的评测流程。

项目简介

判断模型是否真的稳定可用

项目围绕 LLM 与 Agent 的测试与评估展开，通过测试集、Gold Label 与 Rubric，把主观的模型表现转化为可重复比较的评测过程。

评测内容

覆盖 Prompt 版本与典型边界情况

  • Prompt V1 / V2 对比
  • Gold Label
  • Rubric
  • Guardrail
  • Harmful content
  • Sarcasm
  • Ambiguous reference
  • Factual judgement

评测流程

Test Cases→Gold Labels→Prompt / Agent Run→Rubric Scoring→Failure Analysis→Iteration

评估维度

CorrectnessToken CostTurnsReliabilitySafety

项目重点

用测试集与指标替代单次演示

单次展示无法证明质量。项目更关注系统在真实复杂输入下的稳定性，以及 Prompt 或 Agent 变更后能否通过同一套标准进行比较。
