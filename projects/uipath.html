PROJECT 05 / RPA

UiPath WhatsApp Browser Automation

基于 UiPath 的 WhatsApp Web 浏览器自动化工作流。

项目简介

将重复的浏览器操作转化为 RPA 流程

使用 UiPath 完成 WhatsApp Web 浏览器自动化，把人工点击流程拆分为可执行、可复用的工作流。

核心问题

在动态网页中保持流程稳定

网页元素可能异步加载，Selector 可能失效，自动化流程还需要在局部步骤异常时继续安全运行。

项目流程

Trigger→Open Browser→Locate UI Element→Execute Action→Exception Handling

方案重点

  • UI Element 定位
  • Browser Automation
  • Workflow
  • 等待与分支处理
  • Exception Handling
