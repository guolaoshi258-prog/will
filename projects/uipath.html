PROJECT 05 / RPA

UiPath WhatsApp Browser Automation

把房源筛选后的预约沟通封装成可复用的 WhatsApp Web 自动化子流程。

项目背景

从房源资料到看房预约的跨应用流程

完整自动化从租房 PDF 开始：提取房源信息、按预算和通勤等条件筛选、读取日历空闲时间、通过 WhatsApp 联系发布人，并在确认后创建日历预约。流程横跨 PDF、Google Sheets、WhatsApp Web、Agent 与 Google Calendar。

我的模块

独立、可复用的 WhatsApp 子流程

负责将人工沟通步骤拆成 UiPath Studio Web 子流程。发布人的电话号码与自动生成的看房消息作为输入参数传入；流程定位正确联系人、打开对话、输入消息并触发发送。

把通信逻辑与主流程分离后，同一套动作可以循环处理多个房源和联系人，而不需要复制流程节点。

自动化流程

发送动作只是完整闭环的一部分

Accepted Properties→Calendar Availability→Message Arguments→WhatsApp UI Automation→Status to Sheets→Response to Agent→Calendar Re-check→Create Event

系统分工

AI 理解非结构化回复，规则校验关键状态

UI AUTOMATION操作 WhatsApp Web

定位联系人和输入框，发送包含房源信息与候选时间的消息。

GOOGLE SHEETS跨流程状态交接

记录已发送、等待回复和预约结果，保持每套房源可追踪。

DECISION AGENT理解自然语言回复

输出 PROPOSED、NO TIME 或 REJECTED，并在存在建议时提取时间。

DETERMINISTIC CHECK再次检查日历冲突

回复等待期间日历可能变化，因此创建事件前重新校验空闲状态。

可靠性设计

自动化不只是录制点击

  • 通过输入参数复用同一子流程，而不是为每个联系人复制动作
  • 使用明确的 UI Element 定位、等待与步骤状态
  • 消息发送后写回状态，供下一阶段识别待处理记录
  • 将自然语言理解与最终日历验证分开，避免 Agent 直接确认冲突时间

输出

Reusable面向多个房源与联系人的子流程
TraceableGoogle Sheets 中的状态交接
Checked预约创建前的二次冲突校验
