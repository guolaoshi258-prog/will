PROJECT 02 / AI AGENT

企业社媒风险监测 Agent

从页面信息抓取、联网搜索，到模型理解与结构化风险输出。

项目简介

面向企业的持续风险监测

面向企业风险监测场景，支持对社交媒体账号、电商平台店铺等对象进行持续监测。系统通过 Chrome 浏览器插件抓取页面信息，再交由模型进行内容理解和风险分析。

项目流程

先补充上下文，再进行风险判断

监测对象→Chrome 插件抓取→信息预处理→关键词提取→联网搜索→模型理解与风险判断→结构化结果输出

监测对象可以包括社交媒体账号、电商平台店铺，以及品牌或产品相关页面。

模型不会只基于抓取到的单页内容直接判断，而是会先提取关键信息和关键词，再结合联网搜索补充上下文，最后进行理解和分析。

我的工作

Agent 工作流与调用链优化

参与 Agent 工作流设计、模型调用逻辑、Prompt 调整和成本优化，并围绕实际企业使用场景持续调整产品逻辑。

项目结果

≈ 21%token 成本降低
